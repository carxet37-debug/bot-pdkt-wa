# 🤖 Bot WhatsApp PDKT

Bot WhatsApp interaktif untuk game PDKT, icebreaker, dan obrolan seru!

## 📦 Requirements
- Node.js v14+
- npm atau yarn
- WhatsApp Account

## 🚀 Instalasi

1. Clone repository:
```bash
git clone https://github.com/carxet37-debug/bot-pdkt-wa.git
cd bot-pdkt-wa
```

2. Install dependencies:
```bash
npm install
```

3. Jalankan bot:
```bash
npm start
```

4. Scan QR Code dengan WhatsApp Anda

## 📋 Daftar Perintah

| Perintah | Fungsi |
|----------|--------|
| `.menu` | Tampilkan menu utama |
| `.truth` | Pertanyaan kejujuran |
| `.dare` | Tantangan seru |
| `.ask` | Deep talk questions |
| `.ice` | Icebreaker topics |
| `.line` | Gombal PDKT |
| `.help` | Petunjuk penggunaan |

## 💡 Cara Menggunakan

1. Ketik salah satu perintah di atas
2. Bot akan mengirim pertanyaan/tantangan random
3. Jawab dengan jujur dan seru!
